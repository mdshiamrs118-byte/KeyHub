# KeyHub (test build 0.3)

OpenRouter only. Local proxy on 127.0.0.1:8787, multi-key with automatic failover,
usage history, balances, model browser.

Build: push to GitHub, Actions tab -> "Android Build" -> download the KeyHub-debug-apk artifact.

Use in other apps:
  Base URL: http://127.0.0.1:8787/v1
  API key : (the universal key shown on the Home tab)
  Model   : any OpenRouter model ID (Models tab -> tap to copy)
